# Changelog

## v0.1.0-preview.1 - 2026-10-22

Initial technical preview.

- Added the C++17 runtime core and CLI.
- Added ONNX Runtime CUDA/CPU segmentation backend.
- Added model metadata inspection and fixed-batch handling.
- Added VRAM-aware planning, measured batch calibration, and OOM fallback.
- Added edge-anchored tiling, coordinate restoration, and overlap fusion.
- Added colored mask and class-index PNG output.
- Added P50/P95 benchmarks, baseline comparison, seam diagnostics, and mIoU.
- Added single-image, directory-level, and minimal Python APIs.
- Added host scripts for calibration, profiling, sweeps, and batch analysis.
